# SAV-242 — Hosted CI cost control

## Intent

Keep one independent clean-machine validation bound to every merge-ready head
without paying for duplicate feature-branch push runs or intermediate draft-PR
commits.

## Slice

- Change only CI trigger/allocation policy.
- Preserve the full Validate job, PostgreSQL migration proof, Node/Python
  contracts, quality checks, production build, and concurrency cancellation.
- Treat local and Vercel checks as development evidence, never substitutes for
  the final hosted gate.

## Validation

- `node --test scripts/ci-trigger-contract.test.mjs`
- `npm run test:local`
- `npm run check:ci`
- `npx prettier --check .github/workflows/ci.yml scripts/ci-trigger-contract.test.mjs docs/agent-tasks/SAV-242.md docs/operations/ci-cost-control.md`

## Rollout

1. Merge the trigger policy.
2. Keep feature PRs draft during agent implementation and remediation.
3. Mark a PR ready only when independent local review is complete.
4. Record the resulting green hosted Validate run and exact head before merge.
5. Keep `main` and manual dispatch validation enabled.
6. Configure repository protection to require the exact `Validate` context.

Rollback is a workflow-only revert. Do not remove or weaken Validate steps.
