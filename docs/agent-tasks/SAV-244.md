# SAV-244 — Main branch protection

## Intent

Enforce the hosted exact-head validation policy at the repository boundary so a
workflow convention cannot be bypassed during relaunch work.

## Live configuration

- Required context: GitHub Actions `Validate`
- Strict/up-to-date head: enabled
- Admin enforcement: enabled
- Force pushes: disabled
- Branch deletion: disabled

## Validation

1. Confirm a draft PR publishes no successful `Validate` context.
2. Mark an audited PR ready and confirm one exact-head Validate job starts.
3. Confirm merge is blocked while that job is pending or failing.
4. Confirm merge can proceed only after the current head is green.
5. Push a new head and confirm the prior result no longer satisfies protection.

## Rollout and rollback

PR #294 established safe check naming before protection was enabled. Any
break-glass change requires an explicit owner decision, a Linear incident trail,
and immediate restoration with API evidence.
