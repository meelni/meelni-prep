# SAV-487: Owner-Only Production Web Shadow Canary

## Intent

- User request: test the adaptive interviewer through the actual Production
  Meelni web product, not only through a LiveKit transport command.
- Outcome: the authenticated product owner can join one already-authorized
  `production_project_shadow` room through a private Production dashboard
  surface.
- Why now: the merged Shadow operator and worker path are available, but the
  ordinary Production web interview path intentionally remains unwired.

## Slice

- Primary: authenticated interview/session vertical slice.
- Secondary: adaptive-interviewer rollout operations and LiveKit browser UI.
- Skills: Linear workstream, LiveKit runtime, ops connections, architecture,
  vertical-slice playbook, engineering memory and PR preparation.

## Linear Tracking

- Project: Meelni.
- Parent: SAV-476.
- Child: SAV-487.
- State: In Progress.

## Scope

- In: a hidden owner-only Production dashboard page; a strict v2 external
  connection-file contract; browser-memory-only LiveKit credentials; the real
  Meelni voice/transcript presentation; exact Production/topology/config/
  candidate/expiry checks; and a server-side owner/environment gate.
- In: a one-use signed Vercel Production configuration/redeployment action
  whose server-side gate expires within one hour and supports explicit disable.
- Out: ordinary `/api/session/start`, ordinary `/interview`, credits, persisted
  transcripts, feedback generation, customer sessions, Director influence,
  automatic cohorts, default-on, Production rollout or launch authority.
- Assumption: the existing guarded operator remains the only authority that
  allocates a durable lease and creates the one Production-project Shadow room.

## Product Lens

- Audience: the authenticated human product owner only.
- Lever: safe first-party validation of the interview experience before any
  customer rollout.
- Product Compass: this is evidence gathering, not launch readiness or a
  customer-facing feature.

## Technical Plan

- Add a strict client-safe parser for a v2 operator `connection.json` whose
  token is never uploaded, logged, stored, or placed in a URL.
- Add a server component that returns `notFound()` unless the exact Production
  environment, explicit enable flag, owner user ID, active run and worker
  candidate and bounded expiry all match.
- Add a client room surface using LiveKit audio, acknowledged microphone
  controls, in-memory transcript display and explicit disconnect.
- Extend only the operator's private external connection artifact with exact
  candidate/config/session/expiry bindings; do not change allocation or room
  authority.
- Add a guarded Vercel action that binds the exact merged web candidate,
  source Production deployment, owner/run/worker configuration and operation,
  consumes one signature before provider access, writes server-only values by
  stdin and redeploys the signed source.
- Add source contracts proving no imports or behavior changes in ordinary
  session/start/interview paths.

## Rollout

- Risk: high privacy/authority sensitivity, one-owner blast radius.
- Backward compatibility: ordinary product interviews remain byte-for-byte on
  their existing path.
- Evidence: only closed connection/lifecycle states; no token, room name,
  transcript, prompt, provider payload or user identifier.
- Follow-up: after merge, set the five server-only Production gates through a
  separately authorized web configuration action, create one fresh guarded
  room, test, reconcile and disable the web gate.
