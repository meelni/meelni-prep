# SAV-263 — Registry-only main CI cost control

## Intent

Retain one complete clean-machine validation for every merge-ready registry
change without paying for the same full suite again after the one-file registry
PR merges to `main`.

## Slice

- Exclude only `.github/stacked-prs.json` from push-to-`main` CI when it is the
  sole changed path.
- Keep pull-request Validate unfiltered and required.
- Keep stack topology, migration collision, trusted-publisher, branch
  protection, and manual-dispatch behavior unchanged.

## Validation

- `node --test scripts/ci-trigger-contract.test.mjs`
- `npm run test:local`
- `npx prettier --check .github/workflows/ci.yml scripts/ci-trigger-contract.test.mjs docs/agent-tasks/SAV-263.md docs/operations/ci-cost-control.md`
- Parse both workflow files as YAML.
- Inspect live branch protection read-only before handoff.

## Rollout

1. Merge only after the exact PR head passes the required full Validate gate.
2. Confirm a future registry-only merge still triggers `Relaunch Integration
Gates` on `main` but does not start the full CI workflow.
3. Confirm any `main` push containing another path still starts full Validate.

Rollback is a workflow-only revert through a protected PR. Do not change the
required `Validate`, `Trusted Publisher`, or `Migration Collision Publisher`
contexts.
