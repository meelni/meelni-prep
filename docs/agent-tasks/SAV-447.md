# SAV-447 Agent Task Intake

## Intent

- User request: Add a provider-free, default-off execution and comparison seam
  for SAV-441 trusted closed answer blocks and SAV-445 shadow artifacts.
- Product/user outcome: Measure whether independently evaluated closed blocks
  agree with the final batch authority without changing customer feedback or
  interview behavior.
- Why now: Trusted block authority, the bounded evaluator policy, and immutable
  artifact storage are merged and can be composed without activating a model.

## Slice

- Primary slice: Feedback evaluation reliability and shadow measurement.
- Secondary slices: Inngest idempotency, provider-neutral adapter boundaries,
  and durable contract memory.
- Relevant skills: Meelni front door, Linear workstream, feedback evaluation,
  codebase architecture, vertical-slice playbook, engineering memory, and PR
  preparation.

## Linear Tracking

- Project: Meelni.
- Parent slice issue: SAV-438, which remains open.
- Child deliverable issue: SAV-447.
- Current Linear state: In Progress.

## Scope

- In scope: Strict content-free scheduling and report contracts, an independent
  default-off execution capability, provider-neutral evaluator injection,
  SAV-444 deadline/retry classification, deterministic Inngest identity,
  exact-read-before-work, immutable SAV-445 writes, a content-stripping batch
  authority reader, and provider-free replay/privacy/side-effect fixtures,
  including a bounded post-batch wait matching the SAV-444 horizon.
- Out of scope: A live evaluator adapter, provider configuration or spend,
  pre-terminal answer-block authority, LiveKit/interview runtime changes,
  customer feedback lifecycle mutation, UI, insights, billing, database
  migrations, Production action, deployment, activation, or launch.
- Assumptions: Only a successful SAV-441 projection over one terminally frozen
  canonical ledger may produce scheduling intents. Both execution and storage
  capabilities are required before any artifact read or write.

## Product Lens

- Audience: PM candidates whose eventual feedback quality benefits from safer
  evaluation experiments, with no shadow result exposed to them.
- Product lever: Feedback reliability and future delivery latency evidence.
- Product Compass note: Final batch feedback remains the only customer,
  progress, insight, and billing authority.

## Technical Plan

- Core: Versioned intent, batch observation, rate, and content-free comparison
  report parsers/builders.
- Workflow: Gate-first scheduling, per-key evaluation, and comparison handlers
  with injected dependencies and no operational emission.
- Inngest: Content-free bounded events, deterministic IDs and step names, and
  per-key concurrency. The registered production seam has no live evaluator.
- Data: Reuse migration 0039 through its gated exact-key store; add no schema.
- Docs: Add the shadow comparison contract and OpenSpec change, and update the
  accepted program architecture after validation.

## Validation

- Required commands: Targeted core/workflow/config tests, `npm run test:core`,
  `npm run test:workflows`, `npm run typecheck`, `npm run typecheck:tests`,
  calibration runtime verification, `npm run build`, and
  `npm run verify:agent`.
- Fixtures: 1/2/5/10 segmentation, no-trust/integrity failure, stale tuple,
  reconnect/event replay, crash before and after evaluator-step completion,
  retry/deadline/failure classes, missing artifacts, comparison agreement,
  privacy rejection, deletion TOCTOU, late-within-horizon arrival, bounded
  timeout, malformed provider metadata/clock, and side-effect tripwires.
- Manual audit: No imports or calls into customer feedback routes/UI, insights
  mutation, billing/credits, LiveKit/runtime, or a provider SDK.

## Rollout

- Risk level: Medium; the workflow seam is registered but structurally
  default-off and has no live evaluator composition.
- Backward compatibility: Existing batch feedback, SAV-440 verified-prefix
  behavior, SAV-445 storage/privacy, and all customer reads remain unchanged.
- Metrics/events to watch: None until a separately reviewed provider adapter
  and owner-authorized activation exist.
- Follow-up slice: A pre-terminal authority contract would be required before
  claiming true during-interview latency savings.
