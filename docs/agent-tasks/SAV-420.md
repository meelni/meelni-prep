# SAV-420 Agent Task Intake

## Intent

- User request: Replace the technical evidence-limited feedback presentation
  with four truthful review outcomes after SAV-421 lands.
- Product/user outcome: A PM candidate can tell what review was completed, why
  a number is or is not shown, what evidence supports the result, and what to
  do next without mistaking missing coverage or a system integrity failure for
  poor performance.
- Why now: SAV-421 changes numerical eligibility from transcript surface shape
  to rubric-dimension evidence coverage. The feedback route, History, and
  Dashboard need one coherent presentation contract for that result.

## Slice

- Primary slice: Feedback/evaluation presentation.
- Secondary slices: Dashboard/History reviewability, recovery presentation,
  accessibility, responsive behavior, and scored-only metric isolation.
- Relevant skills: `meelni-feedback-evaluation`,
  `meelni-ui-design-system`, `meelni-design-review-orchestrator`,
  `meelni-codebase-architecture`, `meelni-vertical-slice-playbooks`,
  `meelni-engineering-memory`, `meelni-linear-workstream`, and
  `meelni-pr-prep`.

## Linear Tracking

- Project: Meelni.
- Parent slice issue: SAV-410.
- Child deliverable issue: SAV-420.
- Current Linear state: In Progress; behavior implementation blocked on the
  coordinator-provided exact merged SAV-421 `main` SHA.

## Scope

- In scope: Full scorecard, Partial scorecard, Coaching review, and Unable to
  review presentation; supported-dimension-only scores; no partial overall;
  grounded coaching signals, confidence semantics, one prioritized practice
  focus, exact citations; honest Dashboard/History labels; integrity recovery
  and credit-status copy; accessible responsive states; synthetic fixtures;
  contracts and OpenSpec.
- Out of scope: SAV-418 focused-practice persistence, SAV-415 helpfulness
  persistence or instrumentation, evaluator/provider changes, Production or
  provider mutation, customer transcript use, score threshold tuning, and
  launch or merge authorization.
- Assumptions: SAV-421 will supply the canonical closed coverage/result shape.
  SAV-420 will consume that server-owned result rather than infer outcome or
  withheld reason from null scores in the client.

## Product Lens

- Audience: PM candidates reviewing a completed mock interview.
- Activation/retention/monetization/growth lever: Trustworthy post-interview
  value and a clear next practice action.
- Product Compass note: A useful review is preferable to false precision, and
  a system failure must never read as a candidate-performance judgment.

## Validation

- Required commands: targeted core/view-model, feedback component, dashboard,
  API, and fixture tests; `npm run typecheck`; `npm run lint`;
  `npm run test:core`; `npm run test:fixtures`; `npm run verify:agent`.
- Optional/manual checks: Feedback route and History/Dashboard at narrow and
  desktop viewports; keyboard order; accessible names; screen-reader reading
  order; recovery states; exact-citation navigation; reduced motion.
- Fixtures or regression tests needed: Full, partial, coaching, no-reviewable,
  integrity-retry, integrity-credit-recovery, legacy, malformed, unknown
  outcome/reason, equivalent segmentation, and scoreless trend isolation.

- Follow-up slice: SAV-418 owns durable focused-practice entry and SAV-415 owns
