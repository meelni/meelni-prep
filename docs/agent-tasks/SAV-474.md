## Rollout

- Risk level: medium because the slice observes the full-interview runtime, but
  it is default off and structurally disconnected from speech, prompts,
  controller state, transcript writes, settlement, and feedback.
- Backward compatibility: the exact shadow flag defaults off; disabled or
  invalid configuration creates a no-op observer. Slow, failed, timed-out,
  canceled, stale, malformed, or capacity-rejected work is discarded with
  bounded telemetry and cannot change live behavior.
- Metrics/events to watch: contract/policy/adapter versions, typed outcome,
  readiness and execution latency, deterministic estimated cost, freshness,
  comparison category, capacity pressure, and cancellation.
- Follow-up slice: the smallest future owner action is an isolated Preview
  shadow rehearsal with an owner-selected provider/model, explicit spend cap,
  and accepted quality/cost thresholds. SAV-475 owns any influence experiment;
  SAV-476 remains the human-owned rollout decision.
