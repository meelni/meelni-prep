# SAV-332 — Conservative CI change routing

## Intent

- User request: Run only the PR checks that are required while preserving merge
  safety.
- Product/user outcome: Documentation-only changes receive trustworthy merge
  evidence within two minutes; other owned changes skip only demonstrably
  unrelated heavy lanes.
- Why now: SAV-333 reduced full validation to 6m34s; obvious low-risk changes
  can be faster without weakening the full-path fallback.

## Slice

- Primary slice: CI developer latency and merge safety.
- Secondary slices: Hosted Actions cost control and engineering memory.
- Relevant skills: `meelni-linear-workstream`, `meelni-engineering-memory`,
  and `meelni-pr-prep`.

## Linear Tracking

- Project: Meelni.
- Parent slice issue: SAV-331.
- Child deliverable issue: SAV-332.
- Current Linear state: In Progress.

## Scope

- In scope: Merge-diff classification, conservative owned path classes,
  lane conditions, selected/skipped aggregation, adversarial regression
  fixtures, and operations documentation.
- Out of scope: Transitive test inference, Nx/Turborepo, remote caching,
  provider changes, and product behavior.
- Assumptions: Unknown or structurally ambiguous changes must pay the full
  6m34s gate.

## Product Lens

- Audience: Engineers and agents shipping Meelni changes.
- Activation/retention/monetization/growth lever: Engineering throughput and
  launch reliability.
- Product Compass note: A faster result is valuable only when its selection
  policy is inspectable and fails closed.

## Technical Plan

- Likely workflow files: `.github/workflows/ci.yml`.
- Likely tooling files: `scripts/classify-ci-changes.mjs` and its contract
  tests.
- Data or provider dependencies: GitHub Actions only.
- Docs/decisions to update: `docs/operations/ci-cost-control.md`; no ADR is
  needed because the required context and test contracts remain unchanged.

## Validation

- Required commands: Classifier fixtures, parsed workflow contracts,
  `npm run test:local`, `npm run check`, full hosted validation, and a separate
  documentation-only hosted proof.
- Manual checks: Exact classifier outputs, selected/skipped lane conclusions,
  end-to-end elapsed time, and protected context names.
- Regression fixtures needed: Documentation, agent, migration, application,
  mixed, deletion, rename, malformed, empty, config, shared, and unknown diffs.

## Rollout

- Risk level: High because classification controls work behind a protected
  context.
- Backward compatibility: Manual, config, dependency, workflow, classifier,
  deletion/rename, and unknown changes retain all full lanes.
- Metrics/events to watch: Full and docs-only latency, selection outputs,
  unexpected skipped lanes, and branch protection.
- Rollback: Force the classifier to select all full lanes while retaining the
  parallel SAV-333 topology.
