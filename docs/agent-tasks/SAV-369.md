# SAV-369 — Stable candidate answer blocks

## Intent

- User request: Prevent natural PM answers from fragmenting when pauses or STT
  finalization produce multiple canonical candidate events.
- Product/user outcome: Equivalent spoken answers receive the same feedback
  reviewability while every citation still resolves to exact immutable source
  events and text.
- Why now: Canonical transcript rows are an integrity ledger, but row count is
  not a stable evaluation unit and currently changes completion statistics.

## Scope

- In scope: A typed provider-free core derivation; exact source provenance;
  deterministic prompt/response boundaries; segmentation-invariant completion
  statistics, tier, and provider mode; canonical and legacy workflow paths;
  synthetic boundary, security, and citation regressions.
- Out of scope: SAV-421 scoring-policy replacement, rubric changes, transcript
  mutation, database migration, provider grouping, raw transcript telemetry,
  Production data, deployment, and provider mutation.
- Assumptions: Canonical version-2 rows and integrity markers have already
  crossed the existing trust, replay, and injection boundary before grouping;
  only an exact replay anchored by that boundary may advance continuity without
  evidence. Exact replay advances sequence only and cannot reset
  accepted-evidence timing or bridge a long-silence boundary. Non-exact
  replay-family omissions that can affect candidate evidence or prompt binding,
  and conflicting replay continuity, degrade the evaluation snapshot and cannot
  call the evaluator.

## Product Lens

- Audience: PM candidates completing natural spoken mock interviews.
- Activation/retention/monetization/growth lever: Trustworthy coaching and
  repeat practice without STT-shaped evaluation variance.
- Product Compass note: Preserve evidence integrity while removing a transport
  artifact from the evaluation unit.

## Validation

- Required commands: Focused core/workflow/database tests, package and test
  typechecks, core/fixture/agent/workflow/API/UI suites as applicable, lint,
  production build, agent verification, diff checks, hosted ready-PR checks,
  and fresh exact-head independent review.
- Optional/manual checks: None; no provider or Production action is authorized.
- Fixtures or regression tests needed: Synthetic natural PM speech split into
  1, 2, 5, and 10 finals; boundary matrix; replay/injection; legacy persisted
  sessions; exact replay insertion/removal across long silence; exact source
  references, bytes, provider input, and workflow citations.

## Rollout

- Risk level: Medium because the change alters completion statistics and
  evaluation eligibility inputs without changing persisted transcript truth.
- Backward compatibility: Canonical sessions use logical answer-block
  statistics; rows without canonical identity retain the legacy statistics
  path. No stored transcript or citation is rewritten.
- Metrics/events to watch: Existing content-free feedback lifecycle outcomes
  and hosted check results only; no transcript telemetry is added.
- Follow-up slice: SAV-421 may consume the public answer-block projection for
  its separately scoped scoring-policy work.
