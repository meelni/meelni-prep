# SAV-339 — Question Bank discovery controls and results scrolling

## Intent

- User request: Audit and clean up the authenticated Question Bank from design, interaction, and user perspectives.
- Product/user outcome: Candidates can search and filter without losing context while the question results scroll independently.
- Why now: The featured prompt and page-level scrolling made browsing feel secondary and pushed results out of the mobile viewport.

## Slice

- Primary slice: Authenticated Question Bank information architecture and scroll ownership.
- Secondary slices: Responsive row treatment, contextual bookmark actions, and browser regression coverage.
- Relevant skills: `meelni-ui-design-system`, `meelni-design-review-orchestrator`, `meelni-linear-workstream`, `meelni-pr-prep`.

- Project: Meelni

## Scope

- In scope: Remove the featured recommendation, stabilize discovery controls, make results the single scroll owner, preserve search/filter/start/save behavior, and add responsive evidence.
- Out of scope: Public Explore/SEO pages, question data contracts, recommendation logic, and bookmark API changes.
- Assumptions: Existing question data and interview-start URLs remain authoritative.

## Product Lens

- Audience: PM candidates repeatedly browsing real interview questions.
- Activation/retention lever: Reduce the time and friction between intent (“find a question”) and starting practice.
- Product Compass note: Keep the workspace tactical, calm, and explicit; avoid a recommendation competing with a user-initiated browse task.

## Technical Plan

- Likely app files: `components/dashboard/sections/questions.tsx`.
- Likely workflow files: Browser QA harness, fixtures, synthetic fetch, and a SAV-339 browser spec.
- Data or provider dependencies: Existing question and bookmark endpoints only.
- Docs/decisions to update: Canonical dashboard pattern and this task record.

## Validation

- Required commands: Typecheck, test typecheck, lint, formatting, fixture-boundary verification.
- Manual checks: 390px, 768px, and 1280px; single scroll owner; no horizontal overflow; search and save interactions.
- Fixtures: Synthetic 18-question data set with varied companies, rounds, and question lengths.

## Rollout

- Risk level: Low.
- Backward compatibility: Existing filters, links, APIs, and states remain supported.
- Metrics/events to watch: Question Bank view-to-interview-start conversion and search/filter usage when available.
- Follow-up slice: None required for the scoped cleanup.
