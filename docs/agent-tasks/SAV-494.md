# SAV-494: Isolate Production Shadow From Customer Transcript Runtime

## Intent

- User request: continue the bounded adaptive interviewer rehearsal in the real
  Production Meelni voice UI.
- Product outcome: the owner can exercise one synthetic Shadow voice cell while
  ordinary customer interview, transcript, feedback and credit authority remain
  unreachable.
- Why now: the first live pre-room check found that admitted Shadow metadata
  continued into the ordinary transcript writer and lifecycle path. No room,
  provider call, spend or customer data occurred.

## Slice

- Primary slice: LiveKit interview runtime.
- Secondary slices: staging control-plane transport, operator tooling and
  engineering memory.
- Linear: SAV-494, In Progress, child of SAV-482; SAV-476 remains open.

## Scope

- Route exact admitted Shadow job metadata into a dedicated synthetic runner
  before room connection, provider construction or ordinary metadata parsing.
- Use a closed synthetic room contract with no customer session, transcript
  ingest URL, user ID, question-bank record, feedback or credit fields.
- Preserve ordinary voice STT/LLM/TTS and owner-only in-memory transcript
  presentation while sending no transcript to Meelni persistence or analytics.
- Observe finalized synthetic turns through a distinctly named Director API and
  an in-memory state simulator. Do not construct the ordinary controller,
  interviewer tools or influence gate.
- Reconcile exactly one terminal receipt or stop-incomplete incident through
  the existing staging durable control plane.
- Add a bounded Vercel Automation Bypass header to worker admission and terminal
  evidence requests. The bypass crosses Deployment Protection only; it does not
  replace the signed activation, durable lease or worker capability.
- Build an exact Shadow secret snapshot that disables Opik tracing/content and
  includes the temporary bypass secret. Ordinary rollback remains the exact
  eight-key snapshot.

## Out of scope

- Customer session start, transcript persistence, feedback, credits or usage.
- Director influence, tools, Production rollout, default-on or launch GO/NO-GO.
- A second cell or the remaining 28-cell matrix.
- A permanent public staging endpoint or weakening Vercel protection.
