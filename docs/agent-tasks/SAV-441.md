# SAV-441 Agent Task Intake

## Intent

- User request: Define a deterministic trusted closed-answer-block authority
  after the durable runtime-settlement command landed.
- Product/user outcome: A trustworthy completed PM interview answer can remain
  independently usable when a later frozen tail is not verified, without
  allowing that tail to manufacture evaluation authority.
- Why now: SAV-442 made settlement intent durable; Phase 2 next needs a stable
  provider-neutral block-trust seam before any verified-prefix scoring work.

## Scope

- In scope: One additive provider-neutral frozen-authority input, trusted closed
  block projection, explicit closure provenance, segmentation-invariant
  trusted identity, fail-closed integrity states, OpenSpec, contract docs, and
  synthetic calibration fixtures.
- Out of scope: Sparse scores, provider calls, feedback persistence, database
  reads or migrations, workflow activation, UI, analytics, Production,
  deployment, and default-on behavior.
- Assumptions: Canonical events and SAV-369 answer blocks remain the sole
  evidence/citation and grouping authorities. SAV-442 and frozen writer
