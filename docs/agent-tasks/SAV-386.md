# SAV-386 Agent Task Intake

## Intent

- User request: Explain and correct the apparent removal of mute and End
  Interview controls from the authenticated room.
- Product outcome: Once a nonterminal session exists, a candidate can always
  end safely even while LiveKit credentials or transport are unavailable.
- Why now: Code history proves the controls were not removed. Conditional room
  mounting and a full-screen reconnect overlay make both controls disappear in
  exactly the slow-start and recovery states where a safe exit matters most.

## Slice

- Primary slice: Persistent safe-exit controls across interview connection
  states.
- Secondary slices: Honest microphone availability, shared end confirmation,
  focus restoration, and reconnect regression coverage.
- Relevant skills: UI design system, LiveKit interview runtime, vertical-slice
  playbooks, and Linear workstream.

## Linear Tracking

- Project: Meelni.
- Parent issue: SAV-365.
- Related issue: SAV-384.
- Deliverable issue: SAV-386.
- State: In Progress.

## Scope

- In scope: Establish authenticated session ownership before provider
  credentials arrive; render the existing control surface during credential
  loading and reconnect; disable microphone input; keep End enabled; reuse the
  same confirmation and server-owned idempotent end command.
- Out of scope: Microphone access before canonical readiness, alternate end
  workflows, Production deployment, or provider/gate changes.
- Assumptions: An authenticated owner-scoped session read is sufficient to
  authorize showing End; LiveKit transport is not required to submit it.

## Technical Plan

- Move connection ownership establishment to the successful authenticated
  session read rather than token success.
- Reuse `InterviewControls` in credential-loading and reconnect overlays with
  mute disabled and End enabled.
- Hoist the existing end-confirmation modal so every nonterminal connection
  state uses one command path.
- Ignore late credential responses after terminal intent so an end action
  cannot remount or rekey the room.

## Validation

- Page lifecycle tests for delayed credentials and reconnect end behavior.
- Existing room-control, modal, end-reconciliation, and resilience suites.
- Typecheck, test typecheck, lint, design guardrails, and full agent
  verification.
- Manual isolated staging rehearsal remains owner-gated under SAV-384/SAV-365.

## Rollout

- Risk: Medium; UI ownership timing changes, but no server end semantics or
  provider contracts change.
- Backward compatibility: Existing active-room controls and end payloads are
  unchanged.
- Metrics/events: Existing content-free start stages and interview-end outcome
  events; no new identifying telemetry.
- Follow-up: Record warm, cold, reconnect, and exit evidence in isolated
  staging before moving the reliability stack out of Draft.
