# SAV-376 Agent Task Intake

## Intent

- User request: End an interview without trapping the candidate, preserve the
  complete transcript, and make eligible feedback start sooner.
- Product/user outcome: End Interview becomes a fast durable handoff. The
  candidate can leave while Meelni finishes transcript settlement and feedback
  asynchronously.
- Why now: Production recorded a roughly four-minute end request and an
  activated 523-second session with only 55 seconds of durable transcript,
  missing writer settlement, and skipped feedback.

## Slice

- Primary slice: Interview session end and transcript settlement.
- Secondary slices: Feedback lifecycle UI and feedback dispatch latency.
- Relevant skills: Meelni LiveKit interview runtime, feedback evaluation, UI
  design system, codebase architecture, vertical slice playbooks, engineering
  memory, and PR prep.

## Linear Tracking

- Project: Meelni.
- Parent slice issue: SAV-365.
- Child deliverable issue: SAV-376.
- Current Linear state: In Progress.

## Scope

- In scope: Atomic end acceptance, cutoff-bounded ending ingest, recoverable
  background settlement/finalization, immediate lifecycle navigation, faster
  eligible feedback dispatch, safe stage telemetry, and regression tests.
- Out of scope: Rubric or model changes, browser verification, Production gate
  changes, recordings, or use of wall-clock room duration as scoring evidence.
- Assumptions: Lifecycle state remains terminal truth; transcript integrity
  remains fail closed; existing recovery workers remain available.

## Product Lens

- Audience: PM candidates completing a live mock interview.
- Activation/retention lever: Preserve trust at the highest-intent moment and
  return useful feedback without making the candidate babysit infrastructure.
- Product Compass note: The full interview stays interviewer-led and feedback
  remains post-interview and evidence-grounded.

## Technical Plan

- Likely app files: Interview end API/page/modal, feedback lifecycle API and
  status surface, and Inngest registration.
- Likely package/workflow files: Session lifecycle store, transcript cutoff,
  user-end settlement, finalization/dispatch, recovery candidates, provider
  adapter timeouts, and operational events.
- Data/provider dependencies: Postgres/Drizzle, LiveKit, Inngest, OpenAI, and
  PostHog-compatible client analytics.
- Docs/decisions to update: OpenSpec SAV-376, interview completion contract,
  feedback generation contract, and runtime transcript operations.

## Validation

- Required commands: Targeted workflow/API/UI/runtime tests; core, agent, and
  integrations tests; typecheck; lint; build; and verify:agent.
- Optional/manual checks: Browser and Preview LiveKit rehearsal are explicitly
  deferred to the product owner.
- Fixtures: Sanitized 523-second active / 55-second evidence failure, plus a
  recovery case where cutoff-bounded turns and writer settlement arrive while
  the session is ending.

## Rollout

- Risk level: High because the change coordinates lifecycle, transcript,
  feedback, billing, and provider cleanup.
- Backward compatibility: Existing terminal sessions remain immutable;
  duplicate end requests and worker events replay stored state.
- Metrics/events to watch: End acceptance latency, runtime settlement latency
  and outcome, finalization-to-dispatch latency, credit latency, cleanup state,
  feedback generation latency, queue latency, and missing-settlement rate.
- Follow-up slice: Calibrated feedback-model latency bakeoff if bounded output
  and dispatch changes do not meet the target.
