# SAV-444 Agent Task Intake

## Intent

- User request: Implement one feedback-generation deadline and a closed typed
  retry/failure policy across claim, evidence, provider, validation, and
  persistence.
- Product/user outcome: Eligible feedback either converges predictably within
  one bounded budget or reaches an explainable durable failure without stale
  work overwriting authoritative feedback.
- Why now: Provider timeout alone does not bound queue-to-persistence latency,
  and retry ownership was not explicit across provider and durable worker
  layers.

## Slice

- Primary slice: Feedback/evaluation workflow reliability.
- Secondary slices: Inngest replay, database fencing, and content-free
  operations evidence.
- Relevant skills: Linear workstream, feedback evaluation, vertical-slice
  playbooks, engineering memory, and PR prep.

## Linear Tracking

- Project: Meelni.
- Parent slice issue: SAV-437.
- Child deliverable issue: SAV-444.
- Current Linear state: In Progress.

## Scope

- In scope: One event-anchored deadline, typed provider failures and
  `Retry-After`, explicit retry ownership, deadline-aware terminal CAS writes,
  provider-free fixtures, and content-free attempt/stage evidence.
- Out of scope: Provider/model/tier changes, live or paid calls, queue tuning,
  SAV-446 bakeoff decisions, deployment, Production action, and launch.
- Assumptions: Frozen answer-block evidence, dimension coverage, exact event
  fencing, terminal immutability, and Inngest step replay remain authoritative.

## Product Lens

- Audience: Candidates waiting for post-interview feedback.
- Activation/retention/monetization/growth lever: Trust and retention through
  bounded, recoverable feedback generation.
- Product Compass note: Faster failure recovery must not weaken evidence
  integrity or create duplicate provider evaluations.

## Technical Plan

- Likely app files: None.
- Likely package/workflow files: Feedback workflow, dimension-coverage provider
  adapter, generation state store, Inngest adapter, and operations events.
- Data or provider dependencies: Existing Drizzle compare-and-set and existing
  OpenAI adapter only; sanitized/provider-free tests, no configuration changes.
- Docs/decisions to update: Feedback-generation and LLM observability contracts,
  lifecycle SLO operations notes; no new decision because the accepted
  interview-to-feedback decision already authorizes this slice.

## Validation

- Required commands: Focused workflow/evaluator/operations tests,
  `npm run typecheck`, `npm run typecheck:tests`, applicable build checks, and
  `npm run verify:agent`.
- Optional/manual checks: Inspect the diff for provider/model/tier/queue scope
  expansion and verify hosted PR checks reach a terminal result.
- Fixtures or regression tests needed: Transient persistence replay with one
  provider evaluation, transient/permanent failure matrix, budget and
  `Retry-After` boundaries, deadline anchoring, and content-free event shape.

## Rollout

- Risk level: Medium; generation retry and terminal-write behavior changes.
- Backward compatibility: Existing terminal rows remain immutable; existing
  provider model, tier, output cap, queue configuration, and five-minute
  recovery lease remain unchanged.
- Metrics/events to watch: Generation attempt outcome/failure class, remaining
  budget, provider diagnostic category, persistence replays, and final outcome.
- Follow-up slice: SAV-446 may use the typed model/tier/usage seams for a
  provider-free bakeoff and queue-policy decision after supervisor direction.
