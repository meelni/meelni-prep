# SAV-491: Preserve the Production interview dispatch name

## Intent

Restore and protect Production interview-worker startup after the guarded
Shadow secret overwrite removed the required explicit dispatch name.

## Evidence

- Merged source `b8050bbdbf322ae7732fe5a77983a19a00956c05` deployed through the signed
  `production-project-shadow` wrapper.
- The exact-source version became `Available` but the deployment health moved
  to `CrashLoop` before any room, cell, or provider request was created.
- `agent/interview/agent.py` requires `LIVEKIT_INTERVIEW_AGENT_NAME` at worker
  startup, while the overwrite contract omitted that variable.

## Slice

- Require the canonical interview dispatch name in ordinary and Shadow secret
  replacements.
- Apply the same exact dispatch-name requirement to the demo worker contract.
- Reject missing, extra, or wrong dispatch names before signing or provider
  mutation.
- Keep LiveKit project, agent, source, secret digest, and overwrite mode bound
  to the existing Production action.

## Non-goals

- No room allocation, model call, customer influence, default-on, or launch
  authority.
- No raw LiveKit mutation outside the guarded wrapper.
