## Scope

- In: a closed activation request handled only by the existing staging-only
  endpoint; exact deployed SHA/config/target verification; existing Ed25519
  owner verification and durable one-use activation; provider-free request
  preparation.
- Out: LiveKit deployment/room work, database credential reset, customer data,
  Preview influence, Production rollout, default-on or launch authority.
- Assumption: Vercel deployment protection remains an infrastructure fence;
  the signed artifact and durable CAS remain the product authority.

## Technical Plan

- Keep the route thin and delegate activation parsing/behavior to a workflow.
- Import the reviewed public-key registry only at the server entrypoint.
- Bind activation to `VERCEL_GIT_COMMIT_SHA` plus the immutable rollout digests.
- Prepare the private request body locally without printing its capability or
  artifact. Reuse the existing activation receipt contract.
- Add no schema, provider adapter, environment lookup or ordinary app wiring.
