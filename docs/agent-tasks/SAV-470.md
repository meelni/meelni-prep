# SAV-470 Agent Task Intake

## Intent

- User request: replace question-free full-interview database randomness with
  a bounded, deterministic, explainable pre-room ranker.
- Product/user outcome: full interviews choose a useful question consistently,
  preserve explicit launches absolutely, and replay the accepted choice.
- Why now: SAV-468 established the persisted `InterviewBriefV2` compiler path;
  SAV-470 supplies its deterministic question-free selection authority.

## Slice

- Primary slice: interview/session.
- Secondary slices: question catalog, evidence-gated feedback, persistence.
- Relevant skills: start, Linear workstream, question bank, feedback
  evaluation, architecture, LiveKit runtime, engineering memory, vertical-
  slice playbook, PR prep.

## Linear Tracking

- Project: Meelni.
- Parent slice issue: SAV-465 (remains open).
- Child deliverable issue: SAV-470.
- Current Linear state: In Progress.

## Scope

- In scope: provider-free TypeScript ranker; one bounded normalized context;
  explicit-ID early override; evidence-valid feedback signal; compact persisted
  selection receipt and snapshot; safe fallbacks; `InterviewBriefV2` wiring.
- Out of scope: Python/runtime reads, learned recommendations, LLM/provider
  calls, Production mutations, customer-data inspection, launch/default-on
  authorization, or merging.
- Assumptions: the existing accepted brief contract remains authoritative;
  question-free context failures may use the versioned embedded PM fallback.

## Product Lens

- Audience: authenticated PM candidates starting a full mock interview.
- Activation/retention/monetization/growth lever: relevant practice variety and
  reliable interview start.
- Product Compass note: selection happens before the room; the interviewer does
  not teach, score, or fetch product data during the session.

## Technical Plan

- Likely app files: `lib/workflows/start-session.ts`.
- Likely package/workflow files: `packages/core`, `lib/db`, shared synthetic
  fixtures.
- Data or provider dependencies: bounded existing question, activated-session,
  and evidence-validated feedback reads; existing session `config` JSON; no
  provider dependency or migration.
- Docs/decisions to update: deterministic selection contract and OpenSpec.

## Validation

- Required commands: focused core/DB/workflow tests, `test:core`,
  `test:integrations`, `typecheck`, `check`, and `verify:agent`.
- Optional/manual checks: provider-free synthetic selection timing and bounded
  logical-read count; inspect persisted receipt for private-data exclusion.
- Fixtures or regression tests needed: synthetic factor/fallback matrix,
  explicit authority, stable ties, bounded inputs, replay, and brief integration.

## Rollout

- Risk level: medium; pre-room selection behavior changes only for question-free
  full-interview starts.
- Backward compatibility: explicit question launches and existing persisted
  starts do not rerank; old catalog-backed starts load normally.
- Metrics/events to watch: existing content-free question-selection stage
  timing; compact reason, ranker version, and catalog version in start config.
- Follow-up slice: parent-owned launch/release decision under SAV-465; no such
  decision is made in SAV-470.
