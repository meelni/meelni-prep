# SAV-418 Agent Task Intake

## Intent

- User request: extend the durable focused-practice loop to canonical partial
  scorecards and coaching reviews after SAV-369, SAV-421, and SAV-420.
- Product/user outcome: every supported partial or coaching review offers one
  server-owned, resumable, five-minute self-review path grounded in exact
  verified interview evidence, without manufacturing a weakest score.
- Why now: SAV-420 merged at exact `main` SHA
  `ea2799131d0309ef9485821572260acfaa3aaa65` and now supplies the closed
  review outcome and prioritized-focus vocabulary SAV-418 must consume.

## Slice

- Primary slice: Feedback and evaluation -> focused practice.
- Secondary slices: additive core contracts, authenticated persistence/API,
  feedback UI, account privacy, and browser accessibility.
- Relevant skills: Meelni feedback evaluation, vertical-slice playbooks,
  codebase architecture, UI design system, engineering memory, Linear
  workstream, and PR prep.

## Linear Tracking

- Project: Meelni.
- Parent slice issue: SAV-410.
- Child deliverable issue: SAV-418.
- Current Linear state: In Review; SAV-420 is merged and the implementation
  gate is cleared. SAV-415 remains blocked by SAV-418.

## Scope

- In scope: consume the strict SAV-420 review projection; add a discriminated
  focused-practice plan/attempt snapshot for supported partial/coaching
  sources; atomically create/resume/complete it; retain exact internal frozen
  evidence while exposing only an allow-listed customer DTO; add honest
  unavailable/retry states and a return-to-interview path.
- Out of scope: feedback generation or scoring changes, rewriting transcript
  events or answer blocks, new provider copy, helpfulness instrumentation,
  interview credit, LiveKit, Production migrations, provider mutation,
  deployment, launch authorization, or merge.
- Assumptions: immutable transcript events and SAV-369 answer blocks have
  already crossed their strict integrity boundary; SAV-421/SAV-420 parsers
  remain the only numerical/outcome authority.

## Product Lens

- Audience: PM candidates reviewing a completed mock interview.
- Activation/retention/monetization/growth lever: retention and product quality
  through an executable next step after honest scoreless/partial feedback.
- Product Compass note: extend the accepted feedback-to-practice loop without
  reopening positioning, scoring, or launch decisions.

## Technical Plan

- Likely app files: completed-feedback review and focused-practice workspace.
- Likely package/workflow files: focused-practice plan/attempt contracts,
  canonical practice-focus selectors, focused-practice workflow/repository/API,
  and privacy-safe customer projection.
- Data or provider dependencies: additive Postgres migration source only; no
  remote migration or provider action.
- Docs/decisions to update: focused-practice and feedback contracts plus a
  SAV-418 OpenSpec change. No new decision record is needed because the
  governing product and evidence decisions are already accepted.

## Validation

- Required commands: targeted core/workflow/repository/API/UI tests,
  migration lifecycle and account privacy tests, package/workflow/API/UI
  suites, typecheck, lint, build, `npm run verify:agent`, and hosted checks.
- Optional/manual checks: synthetic browser scenarios at mobile and desktop
  sizes, keyboard/focus/announcement behavior, retry/unavailable states, and
  completion -> return-to-interview.
- Fixtures or regression tests needed: full legacy scored compatibility,
  canonical partial/coaching/unavailable, corrupt identities/evidence, source
  drift, cross-owner access, duplicate/replayed/concurrent mutations, and
  equivalent answer segmentation/provider ordering.

## Rollout

- Risk level: high because this crosses strict feedback, persistence, privacy,
  and migration boundaries.
- Backward compatibility: existing focused-practice v1 JSON and scored
  behavior remain readable and unchanged; the new tuple is additive.
- Metrics/events to watch: none added; SAV-415 retains helpfulness/event
  ownership.
- Follow-up slice: SAV-415 may consume the completed focused-practice release
  only after SAV-418 merges under coordinator authorization.
