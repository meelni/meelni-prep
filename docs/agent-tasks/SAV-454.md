# SAV-454 Agent Task Intake

## Intent

- User request: run named, production-shaped synthetic feedback scenarios locally and emit deterministic artifacts for SAV-455.
- Product/user outcome: developers can verify the interview-to-feedback customer projection without customer data, credentials, provider spend, database state, or interview credits.
- Why now: SAV-452 requires every customer-visible scorecard to be complete and locally testable, while the existing production-shaped golden path is trapped inside one test and the current Feedback Lab uses static presentation fixtures.

## Slice

- Primary slice: Feedback and evaluation tooling.
- Secondary slices: Agent experience, package boundaries, and engineering operations.
- Relevant skills: `meelni-feedback-evaluation`, `meelni-codebase-architecture`, `meelni-vertical-slice-playbooks`, `meelni-linear-workstream`, and `meelni-engineering-memory`.

## Linear Tracking

- Project: Meelni.
- Parent slice issue: SAV-452.
- Child deliverable issue: SAV-454.
- Current Linear state: In Progress.

## Scope

- In scope: extract the existing production-shaped golden-path orchestration and in-memory stores into a reusable workflow seam; define versioned scenario, artifact, manifest, and fail-closed decode contracts at the public `@meelni/test-fixtures/synthetic-feedback` boundary; add deterministic list/run/matrix commands; force durable steps through JSON serialization; cover terminal scorecard, coaching, unable, malformed, replay, and segmentation cases; document the local operational and privacy contract.
- Out of scope: browser UI, customer or Production data, database and credit mutations, provider calls, provider/model configuration, LiveKit execution, deployment, merge, and launch authorization.
- Assumptions: artifacts are terminal-only; SAV-455 owns loading/processing lab states. The runner consumes SAV-453's core three-outcome policy and the existing Production presenter/lifecycle decoder rather than defining another outcome classifier, score reducer, presenter, answer grouping, or static scenario catalog.

## Product Lens

- Audience: developers and reviewers validating trustworthy PM interview feedback.
- Activation/retention/monetization/growth lever: feedback reliability and iteration speed.
- Product Compass note: this is local PM interview feedback tooling and does not broaden the product or expose model controls.

## Technical Plan

- Likely app files: none.
- Likely package/workflow files: `packages/test-fixtures/src/feedback-generation.ts`, the explicit public `@meelni/test-fixtures/synthetic-feedback` subpath, a reusable workflow runner under `lib/workflows/`, the existing production-shaped golden-path test, a thin CLI under `scripts/`, `package.json`, and targeted tests.
- Data or provider dependencies: none by default. A future live-model adapter is an explicit opt-in interface only and is not connected to npm scripts or CI in this slice.
- Docs/decisions to update: a synthetic-feedback operations contract and this intake. No new product decision is required; the implementation follows SAV-452/SAV-453 and existing feedback/evidence decisions.

## Validation

- Required commands: synthetic list/run/matrix checks, `npm run test:fixtures`, `npm run test:core`, `npm run test:feedback`, `npm run test:workflows`, `npm run typecheck`, `npm run typecheck:tests`, touched-file lint, `npm run verify:agent`, and hosted checks.
- Optional/manual checks: inspect one emitted manifest and terminal artifact; verify a second run is byte-identical; verify unknown persisted results project to the existing unavailable lifecycle while malformed or unknown artifact schemas decode to `null`; verify the command works with provider environment variables absent.
- Fixtures or regression tests needed: complete scorecard with total, repeated safe markers over complete trusted candidate scope, sparse trustworthy evidence, excluded/unverified tail, no reviewable answer, strict integrity failure, malformed/unknown persisted result, replay/idempotency, and equivalent segmentation.

## Rollout

- Risk level: medium repository-tooling risk because the runner crosses production workflow and presentation contracts, with no runtime or Production mutation.
- Backward compatibility: existing fixture exports and feedback workflow callers remain supported; artifact schemas are additive and versioned; unknown versions fail closed; deterministic output contains only fully synthetic content and content-free diagnostics.
- Metrics/events to watch: command/test exit status and deterministic artifact hashes only. No product analytics or provider observability is added.
- Follow-up slice: SAV-455 consumes the v1 manifest/artifact boundary in the local Feedback Lab; any live-model synthetic lane requires separate explicit authorization and implementation.
