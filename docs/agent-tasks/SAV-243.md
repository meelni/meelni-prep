# SAV-243 — Server-owned interview runtime configuration

## Intent

Prevent public session-start payloads from selecting model providers, models, or voice-runtime tuning. Preserve only accepted interview preferences at the client boundary and resolve operational settings on the server.

## Vertical slice

- Client: send difficulty, duration, hint mode, and question recency only.
- Web workflow: normalize an explicit preference allowlist, resolve server runtime settings, persist/dispatch the resolved config, and return only safe preferences.
- Voice agent: ignore provider/model/voice values in room metadata and resolve them from agent environment defaults.
- Prompt safety: reject non-canonical roles and remove free-form persona text from the start-session, persistence, metadata, and prompt path.
- Contracts/operations: document ownership and coordinated environment configuration.

## Out of scope

- Calling or changing external providers.
- Enabling the relaunch feature flag.
- Changing interview evaluation behavior.

## Validation

- TypeScript contract and workflow tests, including malicious and legacy full-config payloads.
- Python runtime contract tests, including metadata injection and environment overrides.
- `npm run check:ci`
- `npm run build`

## Rollout

Deploy the same non-secret runtime environment settings to the web and voice-agent runtimes. Keep the relaunch flag off. Review the draft PR before merge.
