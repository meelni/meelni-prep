# SAV-425 Agent Task Intake

## Intent

- User request: Add a canonical start skill for any Meelni coding-agent task,
  question, investigation, or implementation request.
- Product/user outcome: Agents begin from current Meelni product and system
  truth, investigate with principal-engineer/CTO judgment, and reach a useful
  answer, recommendation, plan, or safely delivered change.
- Why now: The repository has specialist skills but no shared front door that
  classifies ambiguous or cross-cutting requests before those skills are used.

## Slice

- Primary slice: Agent experience and tooling.
- Secondary slices: Product strategy, architecture, operations, delivery.
- Relevant skills: `skill-creator`, `meelni-start`,
  `meelni-codebase-architecture`, `meelni-product-strategy`,
  `meelni-linear-workstream`, `meelni-engineering-memory`, `meelni-pr-prep`.

## Linear Tracking

- Project: Meelni.
- Parent slice issue: None.
- Child deliverable issue: SAV-425.
- Current Linear state: In Progress.

## Scope

- In scope: Canonical skill, read-only orientation script, routing and
  investigation references, harness symlinks, operations docs, tests, forward
  evaluation, and PR delivery.
- Out of scope: Product behavior, provider state, Production data, and rewrites
  of specialist skills.
- Assumptions: `meelni-start` routes into specialist skills rather than copying
  their workflows.

## Product Lens

- Audience: The product owner and coding agents working on Meelni.
- Primary lever: Product quality and delivery velocity.
- Product Compass note: Better task framing should reduce false starts and
  unsafe action while keeping the live PM interview practice wedge explicit.

## Technical Plan

- Likely app files: None.
- Likely package/workflow files: `.agents/skills/meelni-start/`, harness
  symlinks, and a repository contract test.
- Data or provider dependencies: None.
- Docs/decisions to update: `AGENTS.md` and `docs/operations/skills.md`; no new
  decision record unless validation reveals a durable policy conflict.

## Validation

- Required commands: Skill Creator quick validation, `npm run validate:skills`,
  targeted contract tests, `npm run test:local`, formatting, and
  `npm run verify:agent` before PR handoff.
- Optional/manual checks: Forward-test product recommendation, diagnosis-only,
  and protected operations prompts with independent agents.
- Fixtures or regression tests needed: Routing completeness, harness discovery,
  authority boundaries, and deterministic orientation output.

## Rollout

- Risk level: Medium; the skill influences how future agents begin work.
- Backward compatibility: Additive; specialist skills remain canonical.
- Metrics/events to watch: Qualitative forward-test failures and repeated
  misrouting; no product analytics event is added.
- Follow-up slice: Iterate only from observed agent failures or product-owner
  feedback.
