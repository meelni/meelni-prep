## Rollout

- Risk level: medium; the implementation touches the voice runtime but remains
  unreachable from the entrypoint because the flag defaults off and no trusted
  lifecycle snapshot/refresh boundary exists.
- Backward compatibility: the flag defaults off. Missing inputs, invalid state,
  missing authoritative lifecycle state/version, or any controller failure
  disables the adapter for that session and preserves the existing interviewer,
  transcript, deadline, and settlement paths. Because the current runtime has
  no trusted lifecycle snapshot/refresh boundary, the entrypoint remains fenced
  to the existing interviewer even if the repository-only flag is set.
- Metrics/events to watch: content-free controller version/status, fallback
  reason, clock band, move lifecycle state, and terminal settlement evidence.
- Follow-up slice: SAV-472 may expose accepted controller actions as tools;
  SAV-475 owns evidence-based live enablement; SAV-476 remains the human-owned
  GO/NO-GO boundary.

## Implementation Record

- Base: verified `origin/main` at
  `3a3eddc62c4713437e3ad52608f8660b7c0699f7`; SAV-466, SAV-467, and SAV-468
  contracts and accepted evidence were present before implementation.
- Domain: immutable `deterministic-interview-controller.v1` state, exact integer
  monotonic clock projection, closed reducer events/failures, bounded ledger and
  snapshot, deterministic move policy, delivered-only commit, and exact terminal
  no-op behavior.
- Runtime: a narrow fail-safe adapter correlates finalized candidate identities,
  speech handles, assistant items, canonical transcript events, and post-2xx
  no-prefix interruption markers. The hard deadline and settlement functions
  were not changed.
- Pinned ordering repair: suppressed turns that project elapsed or arrive after
  terminal return normally from the LiveKit 1.6.5 user-turn hook, then consume
  an empty result at the public LLM boundary. The SDK therefore emits the
  finalized user item through the existing persistence path exactly once with
  no interviewer output. Pre-deadline explicit exit still admits and delivers
  one graceful close.
- Generation correlation repair: the public LLM boundary requires the finalized
  candidate message ID and exact controller move snapshot identity before any
  clock or move mutation. A canceled preemptive pipeline is denied state-stably,
  while the matching finalized pipeline may authorize exactly once.
- Exit policy repair: an anchored, twelve-word maximum grammar recognizes
  unambiguous stop/end/finish interview requests. Provider-free positive and
  negative tables prove graceful close without treating ordinary PM answer
  content as exit intent.
- Deterministic fences: the public LLM boundary rechecks monotonic time before
  generation, all recognized events are exact state no-ops after terminal, and
  one delivered transition at the final objective/topic makes the next move a
  close even during warning.
- Lifecycle fence: controller construction requires an explicit durable
  lifecycle state/version. The current entrypoint has no trusted source or
  refresh path, supplies neither, and therefore always retains the base
  interviewer even if the repository-only controller flag is set. No
  `active`/version-1 authority is fabricated.
- Evidence: transcript delivery is observed only from the successful
  `TranscriptIngestQueue.publisher` callback. The optional marker observer runs
  after successful persistence and cannot retry or fail settlement.
