# SAV-333 — Parallel PR validation

## Intent

- User request: Reduce the merge-ready PR gate from more than 15 minutes
  without weakening required checks.
- Product/user outcome: Engineers receive trustworthy merge evidence within a
  seven-minute p90 target.
- Why now: The last 20 successful runs had a 15m21s median and 15m37s p90
  because one job serialized every check.

## Slice

- Primary slice: CI developer latency and merge safety.
- Secondary slices: Hosted Actions cost control and engineering memory.
- Relevant skills: `meelni-linear-workstream`, `meelni-engineering-memory`,
  and `meelni-pr-prep`.

## Linear Tracking

- Project: Meelni.
- Parent slice issue: SAV-331.
- Child deliverable issue: SAV-333.
- Current Linear state: In Progress.

## Scope

- In scope: Four full-coverage lanes, one fail-closed required aggregator,
  lane-specific services and tooling, regression contracts, and operations
  documentation.
- Out of scope: Change-aware routing, reduced browser coverage, merge queues,
  remote caches, and provider or Production changes.
- Assumptions: A modest increase in total runner minutes is acceptable for a
  greater than 50% reduction in developer wait time.

## Product Lens

- Audience: Engineers and agents shipping Meelni changes.
- Activation/retention/monetization/growth lever: Engineering throughput and
  launch reliability.
- Product Compass note: Faster evidence must not lower the trust threshold.

## Technical Plan

- Likely app files: None.
- Likely package/workflow files: `.github/workflows/ci.yml`, `package.json`,
  and CI contract tests.
- Data or provider dependencies: GitHub Actions only.
- Docs/decisions to update: `docs/operations/ci-cost-control.md`; no ADR is
  needed because this is an operational topology revision.

## Validation

- Required commands: YAML parse, CI trigger and quality contracts,
  `npm run test:local`, `npm run check`, `npm run test:ci`,
  `npm run test:database-migrations`, Python agent tests, production build,
  public crawl, and browser QA.
- Optional/manual checks: Live ready-PR lane conclusions, elapsed time, and
  exact required context.
- Fixtures or regression tests needed: Parsed workflow topology and aggregator
  fail-closed assertions.

## Rollout

- Risk level: High because the final job is a protected merge context.
- Backward compatibility: Preserve exact `Validate`, `Manual Validate`, and
  lifecycle semantics.
- Metrics/events to watch: Full workflow and critical-path durations, lane
  results, cancellation behavior, and required context app/name.
- Follow-up slice: SAV-332 adds conservative change-aware routing only after
  this topology is live and measured.
