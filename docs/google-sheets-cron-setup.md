# Question Sync Deployment

This document previously contained executable setup instructions that no longer match the authorization and transaction model. They have been removed to prevent accidental use.

Use the canonical [Question sync operations runbook](operations/question-sync.md) for credentials, deployment, manual invocation, concurrency verification, rotation, and rollback.

Ordinary Meelni sessions and cookies never authorize question sync. Do not create alternate manual-sync procedures outside the canonical runbook.
