## Codebase Patterns

### Database (Drizzle ORM)
- Schema: `/lib/db/schema.ts`
- Client: `import { db } from "@/lib/db"`
- After changes: `npm run db:push`
- UUID PKs: `uuid().primaryKey().defaultRandom()`
- Timestamps: `timestamp("created_at").defaultNow()`

### API Routes
- Location: `/app/api/[name]/route.ts`
- Auth check:
  ```typescript
  const supabase = await createClient();
  const { data: { user } } = await supabase.auth.getUser();
  if (!user) return NextResponse.json({ error: "Unauthorized" }, { status: 401 });
  ```

### Components
- Server components by default
- Client: Add `"use client"` at top
- UI: `/components/ui/` (Button, Card, Badge)
- Dashboard: `/components/dashboard/sections/`
- Charts: recharts library (already installed)

### Styling
- Tailwind v4
- Brand colors via CSS variables
- Animations: `/lib/animations.ts`

## 2026-01-16 - BUG-001: Fix analytics stats showing blank/NaN values
- Fixed stats cards component to handle zero values correctly
- Files changed: components/dashboard/stats-cards.tsx
- **Learnings:**
  - JavaScript treats 0 as falsy, so `averageScore ? value : 'N/A'` shows "N/A" for 0 scores
  - Solution: Use explicit null/undefined checks: `averageScore !== undefined && averageScore !== null ? value : 'N/A'`
  - Same pattern applied to totalMinutes and completionRate for consistency
  - This ensures "0.0/10" displays instead of "N/A" when user has 0 average score
  - Quality gates passed: typecheck (pre-existing test errors only), lint (no new errors in modified file)
