# Adaptive Interviewer Production-Project Shadow Delta

## Requirement: topology is not rollout authority

The system MUST distinguish Production-project transport from rollout
`production_shadow`. It MUST retain Preview-shadow stage, shadow cohort,
exposure none and false influence/default/launch authority.

## Requirement: separated exact authority

Production worker mutation MUST consume an exact Production action and the
run MUST consume a separate exact Shadow owner decision. One room/dispatch
MUST consume a third exact Production action bound to the current deployment
version and closed cell intent. No artifact MUST be accepted by another
domain's verifier.

## Requirement: shared-worker isolation

Only exact private synthetic Shadow metadata MAY construct the Director
runtime. Ordinary Production jobs MUST preserve existing behavior and MUST NOT
construct the Director adapter or call the Shadow control plane.

## Requirement: allocation before provider

Durable allocation MUST commit before Production LiveKit room creation or
dispatch. Any denied, expired, replayed, closed or source-mismatched result MUST
make zero provider calls.

## Requirement: explicit rollback

A stopped/expired run MUST NOT be reported as rollback. The ordinary all-off
worker configuration MUST be restored through a separately authorized guarded
deploy, complete ordinary-secret overwrite and exact source/health postflight.
