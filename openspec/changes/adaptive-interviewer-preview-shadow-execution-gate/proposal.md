# Adaptive Preview-Shadow Execution Gate

## Why

The selected Director adapter is merged but cannot be safely executed: there is
no live-stage authorization, one-time replay fence, attempt-level spend truth,
injected construction boundary, or provider-free lifecycle rehearsal.

## What changes

- Add a closed, exact-SHA/config, one-time Preview-shadow authorization and a
  non-executable pending request generator.
- Add the exact selected Preview-stage configuration and deterministic digest.
- Add an injected, typed default-off/unavailable runtime construction seam plus
  conservative attempt reservation/reconciliation and sanitized evidence.
- Coalesce bounded cleanup and separate confirmed terminal settlement from a
  cleanup-unconfirmed incident that retains budget and stops allocation.
- Rehearse startup, outcome, kill-switch, and bounded settle paths without a
  provider, room, deployment, environment, or customer data.

## What does not change

Application `adapter=None`, all flags off, deterministic controller/speech,
canonical transcript/feedback authority, deployment/provider state,
Production/default-on, and human-owned GO/NO-GO remain unchanged. SAV-476 stays
open. A missing Linear child is recorded locally until connector
reauthentication; no issue ID is invented.
