# Proposal: Execute The Bounded Preview-Shadow Rehearsal

## Problem

The durable authority and private worker envelope are merged, but no trusted
operator tool or Preview worker bootstrap can execute them. Live work must not
be assembled from ad-hoc scripts or ordinary application routes.

## Change

Add a closed owner packet tool, a server-only operator command surface, a
Preview-only worker bootstrap, serial matrix-cell execution, sanitized evidence
and strict source/provider boundaries.

## Non-goals

No customer session wiring, Preview influence, Production shadow/influence,
default-on, launch GO, automatic matrix evidence, or customer data.
