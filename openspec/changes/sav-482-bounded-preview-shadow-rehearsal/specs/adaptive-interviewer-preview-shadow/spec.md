# Adaptive Interviewer Preview-Shadow Execution Delta

## Requirement: exact one-use authority

The system MUST authenticate a fresh exact-merged-SHA Preview-shadow owner
decision and MUST NOT accept pending, expired, replayed, influence, Production,
default-on or launch authority.

## Requirement: allocation before provider

Every live cell MUST commit its durable session lease before LiveKit room or
dispatch construction. Any non-executable admission result MUST make zero
provider calls.

## Requirement: isolated silent worker

Only exact private job metadata in the isolated Preview deployment MAY create
the Shadow runtime. The runtime MUST NOT speak, influence, mutate interview
state, write transcript or feedback, or expose provider/customer content.

## Requirement: honest matrix evidence

The runner MUST execute one declared matrix cell at a time and MUST preserve
`unperformed` for every cell without live terminal evidence.
