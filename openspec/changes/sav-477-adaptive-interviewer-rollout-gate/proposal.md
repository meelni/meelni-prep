# SAV-477: Prepare The Adaptive Interviewer Owner Gate

## Why

The default-off adaptive interviewer contracts are merged, but the human-owned
SAV-476 rollout gate has no adapter selection, provider-backed rehearsal, or
live evidence. Repository prerequisites must make the next decision precise
without performing or pre-authorizing any live action.

## What Changes

- Add a provider-neutral seven-stage rollout policy with exact flags, cohorts,
  version pins, entry requirements, hard stops, and safe rollback targets.
- Require adjacent forward progress and a separate exact-SHA/config owner
  authorization for each Preview and Production step.
- Freeze and verify a sanitized readiness report over accepted synthetic
  benchmark, adjudication, feedback-fixture, and observability-wire evidence.
- Add provider-free default-off, missing-adapter, cohort, revocation, and
  rollback regressions.
- Create a strictly non-authorizing pending template plus a distinct closed,
  value-bearing, domain-separated authorization contract that can authorize
  only preparation of the selected Preview shadow adapter candidate after its
  external owner-decision reference is verified.

## What Does Not Change

Application wiring remains `adapter=None` and all flags remain off. No provider
or Production environment is read, no provider call/spend, deployment, live
room, customer data, Preview influence, Production/default-on, GO/NO-GO, or
merge is included. SAV-476 remains In Progress.
