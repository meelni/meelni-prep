EVERETT FONT - COMMERCIAL LICENSE REQUIRED

This is a placeholder for the Everett font (weight 300).

WHERE TO GET EVERETT:
1. Adobe Fonts (if you have Creative Cloud subscription)
   - Search for "Everett" at fonts.adobe.com
   - Activate the font in your Adobe account
   - Download the web font files

2. Purchase from font foundries:
   - MyFonts: https://www.myfonts.com/
   - Fonts.com
   - Type foundry websites

3. Check with your design team:
   - Your company may already own a license
   - Ask your designer for the font files

WHAT YOU NEED:
- Everett font, weight 300 (Light)
- In .woff2 format (or .ttf/.otf to convert)

FILE NAME REQUIRED:
everett-light.woff2

COST:
Typically $40-200 depending on license type and usage rights.

ALTERNATIVE (FREE):
If you don't have Everett, you can use Public Sans (already included) as a replacement.
Just update layout.tsx to not import Everett and it will fall back to Public Sans.
